
## Rank Ineqs

| Operation              | Property / Inequality                                       | Name                   |
| ---------------------- | ----------------------------------------------------------- | ---------------------- |
| **Sum**                | $\text{rank}(A+B) \le \text{rank}(A) + \text{rank}(B)$      | Subadditivity          |
| **Product (Upper)**    | $\text{rank}(AB) \le \min \text{rank}(A), \text{rank}(B))$  | Product Bound          |
| **Product (Lower)**    | $\text{rank}(AB) \ge \text{rank}(A) + \text{rank}(B) - n$   | Sylvester's Inequality |
| **Invertible Product** | $\text{rank}(PA) = \text{rank}(A)$ _(if $P$ is invertible)_ | Rank Invariance        |
